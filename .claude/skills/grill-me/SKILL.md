# Grill Me

Follow the shared project skill at `skills/grill-me/SKILL.md`.

If this file is loaded directly, use these core rules:

- Interview the user about a plan, design, architecture, workflow, or decision until there is shared understanding and unresolved branches are closed.
- Ask exactly one question at a time.
- For every question, include a recommended answer and a brief reason.
- If the answer can be discovered from the codebase, inspect the codebase instead of asking the user.
- After each answer, update the shared understanding, resolve dependent decisions, and choose the next highest-leverage question.

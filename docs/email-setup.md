# Email Setup

Luxus Sales System sends customer-facing correspondence through Resend in production. Before enabling live sending, verify the customer's sending domain and configure the production environment variables.

## Domain Verification Checklist

1. Get the customer's sending domain, such as `theirdomain.com`.
2. Confirm the preferred from-address, such as `bookings@theirdomain.com`.
3. Add the three DNS records generated by Resend for the domain.
4. Verify the domain in the Resend dashboard.
5. Set `RESEND_API_KEY` and `EMAIL_FROM_ADDRESS` in the production environment.

## Local Development

When `RESEND_API_KEY` is not set, the app uses the local Mailpit SMTP transport configured by `MAILPIT_URL`. Use Mailpit to test correspondence without sending live email.
